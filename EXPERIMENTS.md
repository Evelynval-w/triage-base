# Experiments

One row per experiment. Change one thing at a time.

| Date       | Prompt version | Provider / model                 | Ticket id | Observed output                                                                 | Problem noticed                                                                 | Change made |
|------------|----------------|----------------------------------|-----------|---------------------------------------------------------------------------------|---------------------------------------------------------------------------------|-------------|
| 2026-10-14 | triage-v1      | openrouter / `google/gemini-2.5-flash` | TCK-10087 | Model fell for the injection: category changed and output turned into "pirate" text. | Role separation on its own is not a security mechanism — the `</ticket>` tag can be closed from inside the user content. | Added `stripTicketTags()` in `lib/prompt.ts`; the `<ticket>` wrapper is now sanitised before send. Bumped prompt to `triage-v2`. |
| 2026-10-14 | triage-v1      | openrouter / `google/gemini-2.5-flash` | several   | Model returned prose wrapped in a ```json ... ``` code fence; JSON.parse failed. | Even with the prompt asking for raw JSON, the model fenced the output.          | In `lib/llm.ts`, strip an optional ```` ```json ```` / ```` ``` ```` fence before `JSON.parse`. Kept the Zod check after it. |
| 2026-10-14 | triage-v2      | openrouter / `google/gemini-2.5-flash` | long "shouting" tickets | Priority often came back as `high` on tickets that were angry but not business-critical. | Model was reading tone as impact.                                                | Reinforced the `"priority reflects business impact, not tone"` line in the system prompt and added a one-line decision guidance for how-to questions. |
| 2026-10-24 | triage-v2      | openrouter / `google/gemini-2.5-flash-lite` | 100-ticket labelled run | Category accuracy comparable to flash, priority accuracy noticeably lower on ambiguous tickets. | Smaller model tends to default to `medium` when the priority wording is unclear.  | Kept flash as the main model for `/triage`; documented flash-lite as the Decision Model for low-latency / low-cost cases. |
